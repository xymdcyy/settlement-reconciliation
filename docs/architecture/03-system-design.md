**核心算法**（从现有脚本迁移）：
```python
matched = receipts[
    (receipts.model == return_row.model) &
    (abs(receipts.unit_price - return_row.unit_price) <= 0.01) &
    (receipts.quantity > 0) &
    (receipts.billing_status == 'billed')
].sort_values('invoice_date', ascending=False).iloc[0]
```

## 3. 权限模型

### 3.1 角色

| 角色 | 权限 |
|------|------|
| **财务专员** | 查看/编辑自己负责的客户（台账/核对/开票/红冲） |
| **主管** | 查看全部客户 + 审批扩展列 + 配置引擎 + 用户管理 |
| **系统管理员** | 全部权限 + 数据迁移 + 数据库管理 |

### 3.2 权限控制

**后端**：
```python
@router.get("/api/customers/{customer_id}/receipts")
def get_receipts(customer_id: int, current_user: User = Depends(get_current_user)):
    # 检查权限
    if not has_permission(current_user, customer_id):
        raise HTTPException(403, "无权限访问该客户")
    ...
```

**前端**：
- 工作台只显示"我负责的客户"
- 系统管理菜单仅主管可见

## 4. 工作流

### 4.1 月度对账工作流（有对账单客户）

```
财务专员                      系统                       客户/税务
   │                          │                            │
   │ 1. 导入新方舟导出          │                            │
   ├─────────────────────────▶│ 追加到 receipts             │
   │                          │                            │
   │ 2. 上传客户对账单          │                            │
   ├─────────────────────────▶│ 解析 → customer_statements  │
   │                          │                            │
   │ 3. 运行匹配               │                            │
   ├─────────────────────────▶│ 调用引擎 → match_results    │
   │                          │                            │
   │ 4. 人工核对               │                            │
   ├─────────────────────────▶│ 更新 match_results          │
   │                          │ 标记 receipts.diff_type     │
   │                          │                            │
   │ 5. 生成开票清单            │                            │
   ├─────────────────────────▶│ 导出 Excel                  │
   │                          │                            ├─▶ 开票
   │                          │                            │
   │ 6. 导入已开票清单          │                            │
   ├─────────────────────────▶│ 回填 invoice_no/date        │
   │                          │ 更新 billing_status         │
   │                          │                            │

   ├─────────────────────────▶│ 显示挂账记录                 │
```

## 5. API 设计（核心接口）

### 5.1 台账相关

```
POST   /api/receipts/import          # 导入新方舟导出（层累追加）
GET    /api/receipts                 # 查询台账（筛选/分页）
PUT    /api/receipts/{id}            # 编辑开票状态
POST   /api/receipts/{id}/split      # 拆分行
GET    /api/receipts/export          # 导出Excel
```

### 5.2 核对相关（保留现有）

```
POST   /api/reconciliation/run       # 运行匹配
GET    /api/reconciliation/results   # 查询匹配结果
POST   /api/reconciliation/correct   # 人工纠正
POST   /api/reconciliation/mark-diff # 标记差异
```

### 5.3 开票相关

```
GET    /api/billing/pending          # 可开票清单
POST   /api/billing/generate         # 生成开票清单
POST   /api/billing/import-billed    # 导入已开票清单
```

### 5.4 红冲相关

```
GET    /api/red-flush/returns        # 本月退货记录
POST   /api/red-flush/find-blue      # 自动查找蓝票
POST   /api/red-flush/generate       # 生成确认单
PUT    /api/red-flush/record-red-no  # 回录红通号
```

### 5.5 未决池相关

```
GET    /api/pending-pool             # 未决差异池
PUT    /api/pending-pool/{id}/resolve # 标记已解决
PUT    /api/pending-pool/{id}/to-real # 转为真差异
```
