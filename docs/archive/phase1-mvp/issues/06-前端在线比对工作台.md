# 06 — 前端：在线比对工作台

**What to build:** 在线比对工作台，左右对照表格展示匹配结果，支持筛选、搜索、手动纠正。

**Blocked by:** #04（需要对账结果 API），#05（需要上传页面和路由基础）

**Status:** done ✅ — 已实现；前端构建通过、依赖 API 端到端验证通过（2026-08-20）

**交付内容：**

1. **工作台页面**（`/workspace`）：
   - 顶部选择器：选择客户 + 对账期间
   - 统计摘要栏：匹配率、已匹配数、未匹配我方数、未匹配客户数、总金额差异
   - 状态筛选标签：全部 / 已匹配 / 未匹配 / 已排除

2. **左右对照表格**（`ComparisonTable.vue`）：
   - 左侧：我方签收记录
   - 右侧：客户方结算单
   - 已匹配的行左右对齐，显示匹配类型和置信度
   - 颜色标记：绿色=已匹配、红色=未匹配、灰色=已排除
   - 表格支持按型号、订单号、金额搜索

3. **手动纠正面板**（`CorrectionPanel.vue`）：
   - 点击未匹配行 → 展开操作面板
   - 手动匹配：从下拉列表选择对应记录
   - 解除匹配：确认对话框
   - 忽略：输入原因对话框
   - 备注：文本输入框
   - 操作后实时更新统计摘要

4. **操作反馈**：
   - 操作成功后 toast 提示
   - 统计摘要栏实时更新匹配率
   - 错误操作显示错误信息
