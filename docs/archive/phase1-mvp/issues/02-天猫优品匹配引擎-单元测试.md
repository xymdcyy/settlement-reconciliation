# 02 — 天猫优品匹配引擎 + 单元测试

**What to build:** 从 `天猫优品-智屏-经销.py` 迁移匹配逻辑到 `TmallEngine`，作为插件引擎运行，并编写单元测试。

**Blocked by:** #01 — 需要 MatchEngine 基类和引擎注册表。

**Status:** done ✅ — 已实现并随全流程端到端验证通过（2026-08-20）

**迁移要点：**

1. **引擎目录**（`app/engines/tmall/`）：
   - `engine.py` — `TmallEngine` 类，继承 `MatchEngine`
   - `config.py` — 列映射配置（`SETTLEMENT_COLS`、`RECEIPT_COLS`）

2. **`parse_customer_data()`** — 从原始 DataFrame 转换为 `list[CustomerSettlement]`：
   - 从 `业务主单据编码` 提取 match_key
   - 从 `后端商品名称` 用正则提取型号
   - 提取金额、数量、单价

3. **`match()`** — 两轮匹配逻辑：
   - 第一轮：精确匹配（`match_key|金额|型号` 完全一致）
   - 第二轮：宽松匹配（`match_key|型号` 一致，金额 >= 结算金额）
   - 金额差异记录进入 amount_diff 列表
   - 空 match_key 标记为"订单号为空"

4. **`get_order_number()`** — 获取签收单优先级订单号：审批单号 > NC 订单号 > 平台订单号

5. **单元测试**（`tests/engines/test_tmall_engine.py`）：
   - 使用手造小数据集（每侧 5-10 条记录）
   - 覆盖 6 个场景：
     - 精确匹配
     - 宽松匹配（金额差异 ≤ 结算金额）
     - 金额不一致（差异过大）
     - 无匹配（双方订单号不同）
     - 空匹配键
     - 型号提取（从产品名称提取）
   - 测试纯函数，不依赖数据库或文件系统
