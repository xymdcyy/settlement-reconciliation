# 01 — 项目骨架 + 数据库模型 + 引擎接口

**What to build:** 搭建 FastAPI 项目骨架，创建所有数据库模型，定义 MatchEngine 抽象基类和引擎注册表。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**交付内容：**

1. **FastAPI 应用入口** (`app/main.py`)，包含 CORS 配置和基础路由挂载
2. **SQLAlchemy 数据库配置** (`app/database.py`)，支持 SQLite（开发）和 PostgreSQL（生产）
3. **6 张数据库模型**（`app/models/`）：
   - `customers` — 客户注册表
   - `our_receipts` — 我方签收记录
   - `customer_settlements` — 客户方结算单
   - `match_results` — 匹配结果
   - `correction_logs` — 人工纠正日志
   - `engine_configs` — 引擎配置
4. **Pydantic schemas**（`app/schemas/`）— 对应每张表的请求/响应模型
5. **MatchEngine 抽象基类**（`app/engines/base.py`），包含：
   - `OurReceipt` / `CustomerSettlement` / `MatchPair` / `MatchResult` 数据类
   - `MatchEngine` 抽象类（`parse_customer_data` / `match` / `get_exclude_rules`）
6. **引擎注册表**（`app/engines/__init__.py`）— `get_engine()` / `register_engine()`
7. **引擎模板**（`app/engines/template/engine.py`）— 新客户起步模板
8. **配置文件**（`app/config.py`）— 数据库连接、上传目录等

**数据库设计要点：**
- 开发环境使用 SQLite，生产环境使用 PostgreSQL（ORM 层抽象差异）
- `our_receipts.raw_data` 和 `customer_settlements.raw_data` 在 SQLite 下用 JSON 字段，PostgreSQL 下用 JSONB
- 所有表含 `created_at` 时间戳
- `match_results` 表含 `status` 状态机：pending → matched/unmatched/manual/ignored
