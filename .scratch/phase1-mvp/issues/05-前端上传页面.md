# 05 — 前端：上传页面

**What to build:** Vue 3 上传页面，支持上传我方签收明细和客户方结算单，显示上传状态和导入结果。

**Blocked by:** #03（需要上传 API）

**Status:** done ✅ — 已实现；前端构建通过、依赖 API 端到端验证通过（2026-08-20）

**交付内容：**

1. **Vue 3 项目初始化**（`frontend/`）：
   - Vite 构建，Element Plus UI 组件库
   - 基础路由配置（`/upload`、`/workspace`、`/history`）
   - API 请求封装（`frontend/src/api/index.js`）

2. **上传页面**（`/upload`）：
   - 两个上传区域：我方签收明细、客户方结算单
   - 拖拽上传或点击选择文件
   - 上传时显示进度条
   - 上传成功后显示导入统计（总行数、分配到各客户行数）
   - 上传失败时显示错误信息

3. **上传表单**：
   - 我方签收上传：选择文件 + 输入对账期间（年月选择器）
   - 客户方结算单上传：选择文件 + 选择客户 + 输入对账期间
   - 客户列表从 API 获取

4. **上传历史** — 上传成功后显示最近上传记录列表

- [ ] 上传页面可拖拽或点击选择文件
- [ ] 上传过程中显示进度条
- [ ] 上传成功后显示导入统计信息
- [ ] 上传失败时显示友好错误信息
- [ ] 上传历史记录可查看
