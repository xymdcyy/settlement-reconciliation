# 07 — 报表导出 + 历史查询

**What to build:** 对账结果导出为 Excel 文件，历史对账记录按月查询。

**Blocked by:** #04（需要对账结果数据）

**Status:** ready-for-agent

**交付内容：**

1. **`GET /api/reconciliation/export`** — 导出对账结果 Excel：
   - 参数：客户 ID + 对账期间
   - 生成多工作表 Excel：
     - Sheet1: 对账汇总（匹配率、总金额、差异金额等）
     - Sheet2: 匹配明细（已匹配的记录，含双方数据）
     - Sheet3: 差异明细——我方已签收客户未结算
     - Sheet4: 差异明细——客户已结算我方未签收
     - Sheet5: 金额差异明细
   - SAP 预制模板（可选，作为额外导出动作）

2. **`GET /api/history`** — 历史对账记录查询：
   - 参数：客户 ID（可选）、起始月份、结束月份
   - 返回每个月的对账摘要（匹配率、匹配数、金额差异等）
   - 按月汇总统计

3. **前端历史页面**（`/history`）：
   - 客户选择器 + 月份范围选择器
   - 按月展示对账摘要卡片或表格
   - 点击月份 → 跳转到该月工作台
   - 导出按钮 → 下载该月对账结果 Excel

- [ ] 导出 Excel 包含 5 个工作表，数据正确
- [ ] 导出的 Excel 可在 Excel/WPS 中正常打开
- [ ] 历史页面按月展示对账摘要
- [ ] 点击月份跳转到工作台
- [ ] 从历史页面可导出该月对账结果
