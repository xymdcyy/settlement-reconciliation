# 06 — 核对桌：人工纠正（拖拽匹配/解除匹配/忽略）

**What to build:** 实现人工纠正功能，财务专员可以拖拽未匹配的记录进行人工匹配，可以解除错误的匹配，可以标记记录为忽略（如费用单据），所有操作记录到 `correction_logs` 表。

**Blocked by:** 05 — 核对桌：运行匹配 + 左右对照 UI

**Status:** ready-for-agent

- [ ] 拖拽匹配：从未匹配区域拖拽我方记录到客户方记录（或反向）
- [ ] 解除匹配：取消错误的自动匹配
- [ ] 标记忽略：标记记录为不参与匹配（如费用单据）
- [ ] 所有操作记录到 `correction_logs` 表
- [ ] 前端：拖拽交互 + 操作按钮
